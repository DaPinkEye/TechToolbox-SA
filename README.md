# TechToolbox SA

A free static website for practical IT, networking and CCTV tools.

## Current tools
- IPv4 Subnet Calculator
- CCTV Storage Calculator
- PoE Power Calculator
- Quick IP Address Checker

## Deployment
Designed for GitHub Pages. Replace `YOUR-DOMAIN.example` in `index.html`, `robots.txt` and `sitemap.xml` after choosing the final domain.
