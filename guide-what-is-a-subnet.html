NETWORKING GUIDE

What is a subnet?

Practical explanation for IT technicians and installers

A subnet (short for sub-network) is simply a smaller, logical division of a larger IP network. Instead of putting every device on one giant flat network, we break it into manageable pieces.

Think of a big office building. The whole building has one street address, but inside you have different floors and rooms. A subnet is like one floor — devices on the same floor can talk to each other easily, while traffic going to other floors has to go through a “lift” (the router / gateway).

Why do we use subnets?

  • Organisation – Separate cameras, staff PCs, guest Wi-Fi, printers, etc.
  • Security – You can put firewall rules between subnets.
  • Performance – Broadcast traffic stays inside its own subnet instead of flooding the whole network.
  • IP management – Easier to plan and track addresses.

The two parts of an IP address

Every IPv4 address (e.g. 192.168.1.50) is made of two parts:

  1. Network portion – identifies which subnet the device belongs to
  2. Host portion – identifies the specific device inside that subnet

The subnet mask (or CIDR prefix) tells us where the split is.

Example: IP 192.168.1.50 with mask 255.255.255.0 (or /24)
Network = 192.168.1.0
Host = .50
Usable hosts = 192.168.1.1 – 192.168.1.254

Common subnet sizes technicians see every day

  • /24 (255.255.255.0) – 254 usable hosts – most common for small offices and CCTV
  • /25 – 126 hosts
  • /26 – 62 hosts
  • /27 – 30 hosts
  • /28 – 14 hosts
  • /30 – 2 hosts – often used for point-to-point links

Key terms you need to know

  • Network address – the first address in the range (not usable by a device)
  • Broadcast address – the last address (also not usable)
  • Gateway / Default gateway – usually the first usable IP (e.g. .1) – this is the router that lets traffic leave the subnet
  • Usable host range – everything between network and broadcast

Quick tip for the field

When a device cannot talk to another device, one of the first checks is: “Are they on the same subnet?” If the network portions are different, traffic must go through a router. If there is no route, they will never communicate.
